# MoneyManager 函数说明书

## 项目概述

MoneyManager 是一款简洁的个人记账理财应用，基于原生 JavaScript、HTML 和 CSS 开发，使用 localStorage 实现数据持久化存储。应用支持支出/退款/垫付三种交易类型，提供月份导航、日历选择、批量管理、月度复盘（含趋势图表）、快捷记账、消费热力图和动态预算等功能。

## 数据操作函数

### loadData()
从 localStorage 加载交易记录到全局 `transactions` 数组。兼容旧数据格式，自动为缺失 `subType` 字段的记录补全。

### saveData()
将当前 `transactions` 数组序列化后存入 localStorage，键名为 'mm_transactions'。

### generateId()
生成唯一交易 ID。使用 `Date.now()` 的 36 进制与随机数组合，确保 ID 的唯一性和可读性。

## 工具函数

### getTodayDate()
返回今天的日期字符串，格式为 'YYYY-MM-DD'。用于初始化选中日期和日历高亮。

### getTimeFromTimestamp(ts)
将时间戳转换为 HH:mm 格式的时间字符串。

### formatAmount(amount)
格式化金额显示：

对文本进行 HTML 转义，防止 XSS 攻击。

### darken(hex, percent)
对 hex 颜色进行加深，percent 取值 0-100。用于深浅微调条生成更暗的色块。

### lighten(hex, percent)
对 hex 颜色进行变亮，percent 取值 0-100。用于深浅微调条生成更亮的色块。

### showToast(message)
在屏幕底部显示 Toast 提示，自动 1800ms 后消失。

## 记账功能函数

### addTransaction()
执行核心记账操作：
1. 验证金额输入（支持 `=30.3-11.4` 类表达式计算，以 `=` 开头触发）
2. 检查累计支出是否超限
3. 构建交易对象（含分类、日期、备注等）
4. 特殊处理退款和垫付类型
5. 保存到 transactions 并持久化
6. 清空表单并显示成功提示
7. 调用 setLastAmount() 记录该分类的使用金额

### deleteTransaction(id)
根据 ID 从 transactions 中删除指定记录，保存数据并刷新界面。

## 月度热力图函数

### getDailyExpenses()
返回当月每日支出数据对象，格式为：
```javascript
{
  '2026-05-01': 150,
  '2026-05-02': 80,
  // ...
}
```
支出计算为（支出+垫付-退款），结果非负。在 `renderReview` 中调用。

### getHeatmapLevel(amount, maxAmount)
根据金额和当月最大值返回热力图等级（0-4）：
- 0：无消费或 maxAmount 为 0
- 1：消费比例 ≤ 25%
- 2：消费比例 ≤ 50%
- 3：消费比例 ≤ 75%
- 4：消费比例 > 75%

### renderHeatmap()
在热力图容器中渲染当月消费分布：
1. 计算每日支出和当月最大值
2. 生成月初空白格子（对齐周一）
3. 渲染每日格子，根据消费等级设置背景色
4. 高亮今天，禁用未来日期
5. 绑定点击事件（跳转到该天列表）
6. 绑定悬停事件（显示 Tooltip）

### showHeatmapTooltip(e, date, amount)
显示热力图格子的 Tooltip，包含日期和格式化金额。自动调整位置防止超出视口。

### hideHeatmapTooltip()
隐藏热力图 Tooltip。

## 数据继承函数

### generatePin()
生成 6 位随机 PIN 码，用于加密导出数据的验证。

### translateApiError(status, body)
将 GitHub API 的错误状态码转换为中文错误信息。

### translateNetworkError(err)
将网络错误（TypeError）转换为中文提示。

### translateCryptoError(err)
将加密/解密错误转换为中文提示。

### translateJsonError(err)
将 JSON 解析错误转换为中文提示。

### getErrorMessage(err)
统一错误处理入口，依次尝试各类错误转换。

### encryptData(plaintext, pin)
使用 PBKDF2 + AES-GCM 对数据进行加密：
1. 将明文通过 TextEncoder 转为字节
2. 生成随机 salt（16 字节）和 iv（12 字节）
3. 通过 PBKDF2（100000 次迭代, SHA-256）派生密钥
4. 使用 AES-GCM 加密
5. 将 salt + iv + ciphertext 拼接后 Base64 编码

### decryptData(encoded, pin)
解密 encryptData 加密的数据，逆向执行 Base64 解码 → 拆分 salt/iv/ciphertext → PBKDF2 派生密钥 → AES-GCM 解密。

### deleteGist(token, gistId)
删除 GitHub Gist，404 时视为已删除不报错。

### buildExportData()
构建导出数据对象：
1. 保存当前数据到 localStorage
2. 收集 mm_transactions、mm_budgets、mm_lastAmounts
3. 遍历 localStorage 收集所有 mm_memo_* 键
4. 返回带 version 和 exportedAt 时间戳的结构化数据

### getDataOverview()
获取数据概览信息：交易笔数、最早/最晚月份范围、有预算的月数。

### exportToGist(token, pin)
执行导出流程：
1. buildExportData() 构建数据
2. encryptData() 使用 PIN 码加密
3. POST 到 GitHub Gist API
4. 返回 Gist ID

### importFromGist(gistId, pin)
执行导入流程：
1. GET 从 GitHub Gist API 获取加密数据
2. decryptData() 使用 PIN 码解密
3. JSON 解析并校验数据结构
4. 返回完整数据对象

### initInheritPanel()
初始化数据继承面板：显示总交易笔数、时间范围、预算设置月数。

### switchInheritTab(tab)
切换导出/导入标签页，显示对应面板。

### stopExpiryTimer()
停止 PIN 码过期倒计时定时器。

### startExpiryCountdown()
启动 PIN 码过期倒计时（5 分钟），每秒更新显示，过期后删除 Gist。

### resetExportForm()
重置导出表单状态，恢复已保存的 Token，显示上次导出的 Gist ID 和 PIN。

### handleExport()
处理导出按钮点击：
1. 校验 Token 不为空
2. 生成 PIN 码
3. 调用 exportToGist() 上传
4. 显示成功面板（含 Gist ID 和 PIN）
5. 启动过期倒计时

### handleCopyGistId()
复制 Gist ID 到剪贴板。

### handleCopyPin()
复制 PIN 码到剪贴板。

### handleImport()
处理导入按钮点击：
1. 校验 Gist ID 和 PIN（6 位数字）
2. 用户二次确认（数据将被覆盖）
3. 调用 importFromGist() 下载并解密
4. 清空 localStorage 并写入导入数据
5. 保留现有主题设置
6. 刷新页面

```javascript
const COLOR_SWATCHES = [

```

| 常量 | 类型 | 说明 |

| `COLOR_SWATCHES` | Array | 24 个颜色 (6×4 网格)，4 行：暗背景色、鲜艳强调色、现代艺术色、浅色亮色 |

| `themeColors` | Object | 当前正在编辑的主题颜色对象 |

### updateThemeColorBtn(btnId, color)
更新主题颜色按钮的预览圆点颜色。

### renderShadeBar(baseColor)
渲染深浅微调条（5 个色块：更暗/暗/当前/亮/更亮），通过 darken()/lighten() 生成。

### openColorSwatch(fieldKey)
打开颜色取色面板：
1. 设置 activeColorField
2. 渲染 24 色网格
3. 调用 renderShadeBar() 显示微调条
4. 高亮当前选中的按钮

### closeColorSwatch()
关闭颜色取色面板，清除 activeColorField。

### applySwatchColor(color)
应用选中的颜色：
1. 更新 themeColors 对应字段
2. 调用 updateThemeColorBtn() 更新预览
3. 更新 shade bar
4. 调用 applyTheme() 实时预览
5. 更新预设主题和自定义方案预览

### initThemePanel()
初始化主题设置面板事件绑定：
- 打开主题面板时加载当前主题到 themeColors
- 关闭时恢复原主题
- 点击确定时保存主题到 localStorage
- 绑定 5 个自定义颜色按钮（点击打开取色面板）
- 绑定颜色网格点击（applySwatchColor）
- 绑定深浅微调条点击（applySwatchColor）

### renderThemePreview()
渲染自定义方案预览卡片，当自定义颜色与所有预设不同时显示"自定义方案"标签。

### loadTheme()
从 localStorage 加载主题设置并应用，首次使用默认主题。

### saveTheme()
读取当前 CSS 变量值（accent、bg、expense、income、text、btnTopReviewColor）保存到 localStorage。

### renderThemePresets()
渲染预设主题网格（8 个预设），点击预设时更新所有主题色并实时预览。

### getLuminance(hex)
计算 hex 颜色的相对亮度（0-1），遵循 W3C 标准公式。

### getContrastColor(bgHex)
根据背景色亮度返回对比度合适的字体色（深色背景返回浅色，浅色背景返回深色）。

### getPureContrastColor(bgHex)
返回纯黑/纯白对比色。

### getSecondaryColor(bgHex)
根据背景亮度返回次要文字颜色。

### getMutedColor(bgHex)
根据背景亮度返回弱化文字颜色。

### getDisabledColor(bgHex)
根据背景亮度返回禁用文字颜色。

### hexToRgba(hex, alpha)
将 hex 颜色转换为 rgba 字符串。

### lighten(hex, percent)
将 hex 颜色变亮指定百分比（0-100）。

### darken(hex, percent)
将 hex 颜色变暗指定百分比（0-100）。

### applyTheme(theme)
核心主题应用函数：
1. 根据 bg 亮度计算 cardBg、cardAltBg、inputBg、borderColor
2. 计算阴影颜色和透明度
3. 计算 btnTopReviewColor（accent 和 bg 的中间亮度）
4. 设置所有 CSS 自定义属性（约 40 个变量）
5. 包括：背景、文字、边框、阴影、强调色及其透明度变体
6. 调用 saveTheme() 持久化

## 数据结构

### 交易记录 (Transaction)
```javascript
{
  id: string,          // 唯一标识
  subType: string,     // 'expense' | 'refund' | 'advance'
  amount: number,      // 金额
  category: string,    // 分类名称
  note: string,        // 备注（可选）
  date: string,        // 日期 'YYYY-MM-DD'
  createdAt: number,   // 创建时间戳
  excludeFromBudget: boolean  // 是否不计入预算（待实现）
}
```

### 预算记录 (Budget)
```javascript
{
  amount: number,       // 预算金额
  excludeIds: string[], // 不计入预算的交易ID列表
  target: string,       // 预算目标描述
  workMode: string      // 'single' | 'double'
}
```

### localStorage 键值
| 键名 | 内容 |
|------|------|
| mm_transactions | 交易记录 JSON 数组 |
| mm_theme | 主题配置 `{ accent, bg, expense, income, text, btnTopReviewColor }` |
| mm_memo_${year}_${month} | 月度小结文本 |
| mm_lastAmounts | 各分类上次使用的金额，如 `{"交通": 2, "餐饮": 15}` |
| mm_budgets | 预算配置 JSON 对象 |
| mm_github_token | 保存的 GitHub Token（导出功能） |
