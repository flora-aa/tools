# MoneyManager 函数说明书

## 项目概述

MoneyManager 是一款简洁的个人记账理财应用，基于原生 JavaScript、HTML 和 CSS 开发，使用 localStorage 实现数据持久化存储。应用支持支出/退款/垫付三种交易类型，提供月份导航、日历选择、批量管理、月度复盘（含趋势图表）、快捷记账、消费热力图和动态预算等功能。

## 数据操作函数

### loadData()
从 localStorage 加载交易记录到全局 `transactions` 数组。兼容旧数据格式，自动为缺失 `subType` 字段的记录补全。

### saveData()
将当前 `transactions` 数组序列化后存入 localStorage，键名为 'mm_transactions'。

### generateId()
生成唯一交易 ID。使用 `Date.now()` 的 36 进制与随机数组合，确保 ID 的唯一性和可读性。

## 工具函数

### getTodayDate()
返回今天的日期字符串，格式为 'YYYY-MM-DD'。用于初始化选中日期和日历高亮。

### getTimeFromTimestamp(ts)
将时间戳转换为 HH:mm 格式的时间字符串。

### formatAmount(amount)
格式化金额显示：
- 大于等于 10000：显示为 ¥Xw（万元）
- 大于等于 1000：显示为 ¥Xk（千元）
- 其他：保留两位小数显示

### escapeHtml(text)
对文本进行 HTML 转义，防止 XSS 攻击。

### showToast(message)
在屏幕底部显示 Toast 提示，自动 1800ms 后消失。

## 日期与日历函数

## 记账功能函数

### addTransaction()
执行核心记账操作：
1. 验证金额输入（必须大于0）
2. 检查累计支出是否超限
3. 构建交易对象（含分类、日期、备注等）
4. 特殊处理退款和垫付类型
5. 保存到 transactions 并持久化
6. 清空表单并显示成功提示
7. 调用 setLastAmount() 记录该分类的使用金额

### deleteTransaction(id)
根据 ID 从 transactions 中删除指定记录，保存数据并刷新界面。

## 月度复盘函数

### renderReview()
渲染月度复盘页面：
- 显示时间段、总支出、总笔数、日均支出、单笔最高
- 按分类聚合支出数据并排序
- 显示分类金额柱状条形图
- 显示与上月对比的涨跌信息
- 点击分类进入详情
- 调用 renderHeatmap() 渲染热力图

### showCategoryDetail(category)
显示指定分类的详细支出记录列表：
- 切换详情面板显示
- 按时间倒序列出所有记录
- 调用 drawTrend() 渲染趋势图

### hideCategoryDetail()
隐藏分类详情面板，返回分类排行列表。

### drawTrend(category)
在 Canvas 上绘制指定分类近 6 个月的支出趋势折线图：
- 自动适配设备像素比（DPR）
- 计算数据范围和坐标轴
- 绘制网格线、折线、数据点
- 显示月份标签和数据值标注
- 无数据时显示提示文本

## 快捷记账函数

### getLastAmounts()
从 localStorage 读取各分类上次使用的金额，返回格式为 `{ '分类名': 金额 }`。首次使用返回空对象。

### setLastAmount(category, amount)
记录某分类使用的金额到 localStorage。每次普通记账成功后调用，更新 `mm_lastAmounts` 存储。

### openQuickPanel()
打开快速记账面板，显示分类网格供用户选择。面板从底部滑出动画。

### closeQuickPanel()
关闭快速记账面板，重置选中状态。

### renderQuickCategories()
渲染快速记账面板的分类网格，每个按钮显示分类名称和上次使用的金额。点击分类后直接调用 quickSubmit。

### quickSubmit()
快速记账核心逻辑：
1. 获取该分类上次金额
2. 如果金额为 0 则不提交
3. 检查累计支出上限
4. 构建交易记录（金额+分类+当前日期+无备注）
5. 保存到 transactions
6. 显示 Toast 提示
7. 关闭面板并刷新列表

## 月度热力图函数

### getDailyExpenses()
返回当月每日支出数据对象，格式为：
```javascript
{
  '2026-05-01': 150,
  '2026-05-02': 80,
  // ...
}
```
支出计算为（支出+垫付-退款），结果非负。在 `renderReview` 中调用。

### getHeatmapLevel(amount, maxAmount)
根据金额和当月最大值返回热力图等级（0-4）：
- 0：无消费或 maxAmount 为 0
- 1：消费比例 ≤ 25%
- 2：消费比例 ≤ 50%
- 3：消费比例 ≤ 75%
- 4：消费比例 > 75%

### renderHeatmap()
在热力图容器中渲染当月消费分布：
1. 计算每日支出和当月最大值
2. 生成月初空白格子（对齐周一）
3. 渲染每日格子，根据消费等级设置背景色
4. 高亮今天，禁用未来日期
5. 绑定点击事件（跳转到该天列表）
6. 绑定悬停事件（显示 Tooltip）

### showHeatmapTooltip(e, date, amount)
显示热力图格子的 Tooltip，包含日期和格式化金额。自动调整位置防止超出视口。

### hideHeatmapTooltip()
隐藏热力图 Tooltip。

获取指定月份预算的排除交易ID列表。

计算指定日期的实际支出金额（不含排除项和退款）。

计算从月初到指定日期前一天的累计支出（不含排除项）。

### getDailyBudget(year, month, day)
计算指定日期的日预算：
```
日预算 = (有效预算 - 已支出_从Day1到Day(N-1)) / (当月总天数 - N + 1)
```
采用实时回推策略，每次计算基于当前所有数据。

### getDayStatus(budget, actual)
根据预算和实际支出返回状态：
- 'EMPTY'：无消费或未设置预算
- 'GREAT'：实际 ≤ 预算×80%
- 'GOOD'：实际 ≤ 预算×110%
- 'WARN'：实际 ≤ 预算×150%
- 'OVER'：实际 > 预算×150%

### getDayStatusLabel(status)
返回状态的显示文本和样式类名。

### getBudgetMonthSpent(year, month)
计算指定月份的累计支出金额（含排除项处理）。

### openBudgetPanel(year, month)
打开预算设置面板，可编辑预算金额、目标、工作模式。参数为空时使用当前月份。

### closeBudgetPanel()
关闭预算设置面板。

### prevBudgetMonth()

### nextBudgetMonth()

### loadBudgetToPanel()

### saveBudget()

### deleteBudgetConfig()
删除当前面板月份的预算配置，需用户确认。

### renderBudgetOverview()
渲染预算概览面板：
- 显示月预算、已支出、剩余金额
- 预算进度条
- 今日可用预算和剩余天数

### renderDayBudgetList()

### isWeekend(date, workMode)

### toggleExclude(transactionId)

## 数据结构

### 交易记录 (Transaction)
```javascript
{
  id: string,          // 唯一标识
  subType: string,     // 'expense' | 'refund' | 'advance'
  amount: number,      // 金额
  category: string,    // 分类名称
  note: string,        // 备注（可选）
  date: string,        // 日期 'YYYY-MM-DD'
  createdAt: number,   // 创建时间戳
  excludeFromBudget: boolean  // 是否不计入预算（待实现）
}
```

### 预算记录 (Budget)
```javascript
{
  amount: number,       // 预算金额
  excludeIds: string[], // 不计入预算的交易ID列表
  target: string,       // 预算目标描述
  workMode: string      // 'single' | 'double'
}
```

### localStorage 键值
| 键名 | 内容 |
|------|------|
| mm_transactions | 交易记录 JSON 数组 |
| mm_memo_${year}_${month} | 月度小结文本 |
| mm_lastAmounts | 各分类上次使用的金额，如 `{"交通": 2, "餐饮": 15}` |
| mm_budgets | 预算配置 JSON 对象 |
