# MoneyManager - 个人记账与月度预算管理

一个纯前端的个人记账单页应用，所有数据存储在浏览器 `localStorage` 中。

## 技术栈

- **HTML5** — 语义化结构
- **CSS3** — CSS 变量驱动的主题系统、响应式设计
- **JavaScript (ES6+)** — 原生 JS，零依赖

## 核心功能

### 记账
- 记录每笔支出的金额、分类、日期、备注
- 支持普通支出、垫付、退款三种子类型
- 快速记账：基于历史金额一键记录
- Enter 键快捷提交

### 账单管理
- 按日期分组的账单列表
- 编辑/删除单条账单
- 批量操作：多选后批量删除、改分类、改日期
- 移动端滑动多选

### 月度复盘
- 月度总支出、日均、笔数、单笔最高统计
- 分类排名（与上月对比变化）
- 分类详情：近 7 个月趋势图（Canvas）
- 每日预算追踪（热力图）
- 月度小结文本

### 预算管理
- 设置月度预算金额、目标、工作模式（双休/单休）
- 动态日预算 = 剩余预算 / 剩余天数
- 每日支出状态监控（优秀/良好/警告/超支）
- 可排除特定账单不计入预算

### 双页模式
- 宽屏（>=768px）下，记账表单和月度复盘左右分栏显示
- 窄屏下自动切换为单页模式

### 主题系统
- 8 套预设主题：经典紫、商务蓝、森林绿、暖阳橙、极简灰、玫瑰粉、日间模式、护眼绿
- 自定义颜色：主题色、背景色、支出色、收入色
- 自动计算对比色和透明度变体

### 数据管理
- 清除本月数据
- 清除全部数据
- 所有数据存储在 `localStorage`

## 快速开始

直接在浏览器中打开 `index.html` 即可使用，无需构建步骤或服务器。
