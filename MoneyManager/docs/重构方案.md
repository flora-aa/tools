## 拆分策略

### 原则

1. **按功能模块拆分**，每个模块独立文件
2. **全局共享变量和常量**放在基础模块
3. **不改变现有逻辑**，仅做文件拆分
4. **CSS 与 JS 模块对应**，便于维护
5. **使用 ES Module 方式**（通过 script 标签顺序加载，不使用 import/export 以保持兼容性）

### JS 拆分方案

```
js/
├── constants.js          # 全局常量：CATEGORIES, MAX_TOTAL, THEME_PRESETS, ALL_OVERLAYS
├── state.js              # 全局状态变量：transactions, currentYear, currentMonth 等
├── utils.js              # 工具函数：generateId, getTodayDate, formatAmount, showToast, escapeHtml
├── storage.js            # 数据持久化：loadData, saveData, getMemoKey, loadMemo, saveMemo
├── theme.js              # 主题系统：THEME_PRESETS, applyTheme, loadTheme, saveTheme, 颜色计算
├── overlay.js            # Overlay 系统：openOverlay, closeAllOverlays, initOverlaySwipe
├── calendar.js           # 日历系统：openCalendar, closeCalendar, renderCalendar, 导航
├── categories.js         # 分类系统：populateCategories, populateEditCategories
├── transaction.js        # 记账操作：addTransaction, deleteTransaction, prevMonth, nextMonth
├── list.js               # 列表渲染：renderList, getMonthTransactions, updateMonthExpense
├── review.js             # 月度复盘：renderReview, renderReviewSummary, renderReviewRank, 趋势图
├── quick.js              # 快捷记账：getLastAmounts, setLastAmount, openQuickPanel, quickSubmit
├── heatmap.js            # 热力图：getDailyExpenses, getDayHeatLevel, renderHeatmap
├── budget.js             # 预算系统：预算 CRUD, 预算概览, 每日预算追踪
├── edit.js               # 编辑面板：openEditPanel, saveEdit, deleteFromEdit
├── batch.js              # 批量操作：toggleSelectMode, initSwipeSelect, batchDelete 等
├── data.js               # 数据管理：openDataPanel, clearCurrentMonth, clearAllData
├── main.js               # 入口文件：DOMContentLoaded 事件绑定，初始化
```

### 拆分要点

1. **零逻辑修改** — 所有代码原样提取，未修改任何函数逻辑
2. **零注释添加** — 不添加额外注释，保持代码整洁
3. **保留原始文件** — style.css 和 script.js 保留为备份参考
4. **按功能聚合** — 每个 JS 模块对应一个独立文件，便于定位和维护
5. **CSS 与 JS 对应** — 样式文件与脚本文件的模块划分保持一致
